## Python و تست‌نویسی

1. [تست‌نویسی با Pytest به زبان فارسی](https://github.com/3lf/pytest-for-humans) — راهنمای فارسی برای یادگیری pytest و ساخت تست‌های Python.
2. [ساختمان داده در Python](https://github.com/alireza-fa/data-structures-python) — معرفی و پیاده‌سازی ساختمان داده‌ها با Python.
3. [Python Crash Course در فرادرس](https://faradars.org/courses/crash-course-of-python-fvpht007) — مرور فشرده‌ی مفاهیم اصلی Python در یک منبع رسمی آموزشی.

## هوش مصنوعی و LLM

1. [LLM برای آدمیزاد](https://github.com/3lf/llm-for-humans) — راهنمای فارسی برای درک بهتر مدل‌های زبانی و استفاده‌ی عملی از آن‌ها.
2. [آموزش نظریه زبان‌ها و ماشین](https://blog.faradars.org/%d8%af%d8%a7%d9%86%d9%84%d9%88%d8%af-%d8%b1%d8%a7%db%8c%da%af%d8%a7%d9%86-%da%a9%d8%aa%d8%a7%d8%a8-%d8%a2%d9%85%d9%88%d8%b2%d8%b4-%d9%86%d8%b8%d8%b1%db%8c%d9%87-%d8%b2%d8%a8%d8%a7%d9%86-%d9%87%d8%a7/) — منبع فارسی درباره‌ی زبان، گرامر و ماشین‌های محاسباتی.

## مهندسی نرم‌افزار و طراحی

1. [Design Patterns برای آدمیزاد](https://github.com/3lf/design-patterns-for-humans) — توضیح الگوهای طراحی نرم‌افزار با زبان ساده و مثال‌های قابل فهم.
2. [الگوهای طراحی به بیان ساده](https://www.developit.ir/design-patterns/) — منبع فارسی برای درک و پیاده‌سازی Design Patternها.
3. [الگوهای مدرن در نرم‌افزار](https://github.com/systemDesignFarsi/modern_software_fa) — مجموعه‌ای فارسی درباره‌ی معماری، ابزارها و روش‌های توسعه‌ی نرم‌افزار مدرن.
4. [Refactoring به زبان فارسی](https://www.developit.ir/refactoring/) — مرجع فارسی برای تکنیک‌های بازآرایی و بهبود ساختار کد.
5. [دوره ویدئویی الگوهای طراحی نرم‌افزار](https://www.youtube.com/playlist?list=PLhD5YGv8gWSyYlm9oNto3xxZ5yYk12K1b) — پلی‌لیست فارسی درباره‌ی Design Patternها.
6. [معماری نرم‌افزار](https://www.youtube.com/watch?v=mexiRfX37fU&list=PLN5rV4x2x5XcRubBzzDQ_WApzFBPAgnoh) — مجموعه‌ی ویدیویی فارسی درباره‌ی مفاهیم معماری نرم‌افزار.
