# منابع رایگان برنامه‌نویسی فارسی

فهرستی منتخب از کتاب، متن آموزشی، دوره و کانال برای فارسی‌زبان‌هایی که می‌خواهند برنامه‌نویسی یا مهارت فنی تازه‌ای یاد بگیرند. از یک موضوع و یک منبع شروع کنید؛ این فهرست جای تمرین و ساخت پروژه را نمی‌گیرد.

[![کنترل محتوا](https://github.com/AlirezaBelal/persian-programming-resources/actions/workflows/content-integrity.yml/badge.svg)](https://github.com/AlirezaBelal/persian-programming-resources/actions/workflows/content-integrity.yml)

> **وضعیت بررسی — ۲۲ اکتبر ۲۰۲۶:** عنوان‌ها، دسته‌بندی‌ها و پیوندهای داخلی مرور شده‌اند؛ دسترسی کامل، رایگان‌بودن و مجوز همه منابع خارجی تأیید نشده است. وضعیت نامطمئن در هر صفحه مشخص شده؛ موفقیت CI فقط سلامت ساختار فهرست را نشان می‌دهد.

برای پیدا کردن فناوری خاص، در صفحه دسته با جست‌وجوی مرورگر نام فارسی یا انگلیسی آن را جست‌وجو کنید. لازم نیست همه منابع یک موضوع را ببینید.

## معنی وضعیت منابع

- **ناشر رایگان اعلام می‌کند:** صفحه رسمی هنگام بررسی، منبع را رایگان معرفی کرده است؛ این یادداشت تأیید پخش تک‌تک جلسات، گواهی رایگان یا مجوز بازنشر نیست.
- **نیازمند بررسی دسترسی:** رایگان‌بودن کامل یا دسترسی فعلی تأیید نشده؛ پیش از انتخاب دوره، شرایط ناشر را بخوانید.
- **مجوز ترجمه نیازمند بررسی:** اجازه صاحب اثر اصلی برای ترجمه در این ممیزی روشن نشده؛ این برچسب حکم نقض حق نشر نیست.
- **منبع قدیمی:** برای مبانی یا مرور تاریخی نگه داشته شده؛ نسخه ابزار و مستندات فعلی را تطبیق دهید.

پاسخ 403، 429، محدودیت منطقه‌ای یا خطای موقت به‌تنهایی دلیل حذف لینک نیست. همین‌طور بازشدن صفحه معرفی، رایگان‌بودن کل دوره را ثابت نمی‌کند. YouTube ممکن است بسته به منطقه یا وضعیت انتشار در دسترس نباشد.

## معیار انتخاب

منبع باید مرتبط با برنامه‌نویسی، علوم کامپیوتر یا مهارت فنی، دارای توضیح دقیق و مناسب مخاطب فارسی‌زبان باشد. اولویت با صفحه اصلی سازنده، ناشر یا مستندات رسمی است. برای پیشنهاد جدید، شاهدی از دسترسی بدون پرداخت و منشأ مجاز ارائه کنید؛ ثبت‌نام و هزینه گواهی را جدا توضیح دهید.

اسکن بدون مجوز کتاب تجاری، دوره افشاشده، حساب اشتراکی، دورزدن محدودیت پرداخت، فایل اجرایی ناشناس و تبلیغ یا لینک همکاری در فروش پنهان پذیرفته نمی‌شود. این مخزن محتوای دیگران را میزبانی یا بازنشر نمی‌کند.

## مشارکت و گزارش مشکل

برای پیشنهاد منبع از [فرم فارسی](https://github.com/AlirezaBelal/persian-programming-resources/issues/new?template=resource.yml) و [راهنمای مشارکت](CONTRIBUTING.md) استفاده کنید. پیشنهادها پس از بررسی پذیرفته می‌شوند، نه خودکار.

برای لینک خراب، تغییر هزینه یا دسته‌بندی اشتباه، Issue یا PR بفرستید و نام منبع، URL عمومی و مشکل مشاهده‌شده را بنویسید. اطلاعات خصوصی یا اعتبارنامه را در گزارش عمومی نگذارید؛ [راهنمای امنیت](SECURITY.md) و [قواعد همکاری](CODE_OF_CONDUCT.md) را ببینید.

کنترل محلی، بدون اینترنت یا نصب وابستگی:

```bash
python tests/content_contract.py
python -m unittest discover -s tests -v
```

این کنترل‌ها فایل‌ها، UTF-8، لینک‌های نسبی، شناسه تیترها و الگوهای آشکار ناامن را بررسی می‌کنند؛ درباره کیفیت آموزشی، دسترسی خارجی یا حقوق نشر تصمیم نمی‌گیرند.
